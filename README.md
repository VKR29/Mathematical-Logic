# Mathematical Logic

Lecture notes, solved past problems and practice tests for the course *Mathematical Logic* at Chennai Mathematical Institute (CMI), taught by M. Praveen. Everything here was written by Vardhan Kumar Ray, a teaching assistant for the course. It is a supplement, not an official course document, and it has not been checked by the instructor.

## Lecture notes

`Notes.pdf` follows the course as taught in August–November 2025. It also contains complete proofs of results that were only stated or sketched in class, more examples, and some supplementary material. The sections are:

1. Propositional logic: syntax and semantics, expressive power, compactness
2. Propositional proofs and resolution: sequent calculus, normal forms, resolution
3. First-order logic: signatures and structures, terms and formulas, semantics, substitution, definability
4. Homomorphisms and definability
5. Henkin witnesses and compactness
6. First-order sequent calculus: rules, soundness, completeness
7. Skolemisation and Herbrand's theorem
8. Unification and first-order resolution
9. Undecidability of first-order logic, via two-counter machines
10. Presburger arithmetic
11. Complete instantiation and set constraints
12. Craig interpolation

The solutions to past problems refer to results by their numbers in these notes, for example "Theorem 4.3 of the lecture notes".

## Note on paths of length n

`FO_P3P4_paths_walks_trails.pdf` studies a problem from the 2025 endsemester exam. The logic has two binary relation symbols, P3 and P4, for "there is a path of length 3" and "there is a path of length 4". The problem asks for a first-order formula saying "there is a path of length n" for each n ≥ 5. The note settles the question for every n ≥ 0 for simple paths, trails and walks, mainly using the automorphism theorem from the course. It ends with a section on directed graphs.
